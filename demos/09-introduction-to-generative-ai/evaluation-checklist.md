# Reference card: evaluating AI-generated code

Keep this open whenever you use an AI assistant.

| # | Question | How to check |
|---|---|---|
| 1 | **Does it run?** | Run it. Read the whole error message if it fails. |
| 2 | **Does it answer the question I asked?** | Re-read your prompt. Check filters (year, product, partner). |
| 3 | **Is the answer right?** | Compare with a known result: a hand calculation, Excel pivot or published figure. |
| 4 | **Do the functions and APIs exist?** | Look them up in the official documentation. |
| 5 | **Are there hidden assumptions?** | Units, missing values, duplicates, which year, how "total" is defined. |
| 6 | **Is it readable?** | Could a colleague maintain it? Are names meaningful? |
| 7 | **Is it safe?** | No hard-coded secrets, no sensitive data sent out, no disabled security checks. |
| 8 | **Would I sign my name to it?** | You are accountable for the code, not the AI assistant. |
